Rive 比較デモ

これは Rive 公式の公開サンプル（vehicles.riv）です。 うおちゃんの絵ではありませんが、Rive で作り込んだらどれくらいリッチに動かせるか／インタラクションがどれくらい滑らかかを体感するためのものです。

このデモで見てほしいポイント

  • 動きの滑らかさ ― ベジェ曲線ベースで補間されるので、p5.js のサイン波変形より遥かに自然
  • 状態遷移 ― idle → 加速 → 減速のような切り替えがエディタで設計可能（state machine）
  • 軽さ ― ベクター描画＋WebGL2 なので、画像スプライトより軽くて鮮明
  • これを「うおちゃん版」にすると ― Rive エディタ（無料）でうおちゃんのレイヤー画像を取り込み、骨組みと state machine を作り込む必要あり（学習コストはここ）

Rive 採用時のワークフロー

  1. Rive エディタ（rive.app、ブラウザ・無料）でアカウント作成
  2. うおちゃんのレイヤー分け画像（前回案内した body/head/arm/leg 等）をインポート
  3. 各パーツに骨を入れ、idle / approach / speak の各アニメーションを作成
  4. .riv として書き出し、`assets/uochan.riv` に置く
  5. このページの src をそのファイルに差し替え、Python 側からは state machine の input をいじって動きを切り替える

p5.js（今のうおちゃん版）との比較

  • 初期コスト：Rive はエディタ習得が必要（数日〜）／p5.js は今すぐ動く
  • 動きの質：Rive ＞＞ p5.js（特に「寄ってくる時の生き物感」「話す時の口パク」）
  • ラズパイ動作：両方軽い（Rive は WebGL2 必須なので Pi 5 推奨）
  • 後からの調整：Rive はエディタ操作で済む／p5.js はコード書き換え
